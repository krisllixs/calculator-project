# Документація API

## Модуль Calculator

Простий консольний калькулятор з шістьма арифметичними операціями.

---

### Функція add()

```python
def add(a, b):
    """Додавання двох чисел"""
    return a + b
```

**Параметри:**
- `a` (float): Перше число
- `b` (float): Друге число

**Повертає:**
- `float`: Сума двох чисел

**Приклад:**
```python
result = add(5, 3)
print(result)  # Виведе: 8
```

---

### Функція subtract()

```python
def subtract(a, b):
    """Віднімання двох чисел"""
    return a - b
```

**Параметри:**
- `a` (float): Зменшуване
- `b` (float): Від'ємник

**Повертає:**
- `float`: Різниця двох чисел

**Приклад:**
```python
result = subtract(10, 4)
print(result)  # Виведе: 6
```

---

### Функція multiply()

```python
def multiply(a, b):
    """Множення двох чисел"""
    return a * b
```

**Параметри:**
- `a` (float): Перший множник
- `b` (float): Другий множник

**Повертає:**
- `float`: Добуток двох чисел

**Приклад:**
```python
result = multiply(6, 7)
print(result)  # Виведе: 42
```

---

### Функція divide()

```python
def divide(a, b):
    """Ділення двох чисел"""
    if b != 0:
        return a / b
    else:
        return "помилка ділення на нуль!"
```

**Параметри:**
- `a` (float): Ділене
- `b` (float): Дільник

**Повертає:**
- `float`: Результат ділення
- `str`: Повідомлення про помилку, якщо `b = 0`

**Приклад:**
```python
result = divide(10, 2)
print(result)  # Виведе: 5.0

result = divide(10, 0)
print(result)  # Виведе: помилка ділення на нуль!
```

---

### Функція power()

```python
def power(a, b):
    """Піднесення числа a до степеня b"""
    return a ** b
```

**Параметри:**
- `a` (float): Основа степеня
- `b` (float): Показник степеня

**Повертає:**
- `float`: Результат піднесення `a` до степеня `b`

**Приклад:**
```python
result = power(2, 10)
print(result)  # Виведе: 1024
```

---

### Функція modulo()

```python
def modulo(a, b):
    """Остача від ділення"""
    if b != 0:
        return a % b
    else:
        return "Помилка: ділення на нуль!"
```

**Параметри:**
- `a` (float): Ділене
- `b` (float): Дільник

**Повертає:**
- `float`: Остача від ділення `a` на `b`
- `str`: Повідомлення про помилку, якщо `b = 0`

**Приклад:**
```python
result = modulo(10, 3)
print(result)  # Виведе: 1
```

## Інтерактивний режим

Під час запуску скрипта програма працює в нескінченному циклі.

**Підтримувані операції:**

| Символ | Операція                | Функція      |
|--------|-------------------------|--------------|
| `+`    | Додавання               | `add()`      |
| `-`    | Віднімання              | `subtract()` |
| `*`    | Множення                | `multiply()` |
| `/`    | Ділення                 | `divide()`   |
| `**`   | Піднесення до степеня   | `power()`    |
| `%`    | Остача від ділення      | `modulo()`   |

**Алгоритм роботи:**
1. Користувач вводить операцію (або `exit` для виходу).
2. Якщо операція невірна, виводиться повідомлення і запит повторюється.
3. Користувач вводить два числа.
4. Виводиться результат.
5. Якщо введено не число, виводиться `Помилка! Введіть дійсне число.`

**Приклад сесії:**
```
=== Простий калькулятор ===
Операції: +, -, *, /, **, %
Для виходу введіть 'exit'

Введіть операцію (+, -, *, /, **, %,): +
Введіть перше число: 5
Введіть друге число: 3
Результат: 8.0

Введіть операцію (+, -, *, /, **, %,): exit
До побачення!
```
